# Security and Responsible Research Policy

This project is limited to defensive testing in controlled environments.

Allowed:
- Android emulators
- personally owned Pixel devices
- synthetic test files and accounts
- test applications created for this project
- observations necessary to verify whether a documented security boundary behaves as expected

Not allowed:
- testing third-party accounts or devices without authorization
- persistence, stealth, credential theft, destructive behavior, or real-data exfiltration
- publishing actionable exploit details for an unpatched vulnerability
- automating attacks against public services

If a genuine vulnerability is observed, preserve the minimum evidence needed for reproducibility, stop escalation, and report it through the appropriate vendor vulnerability-reward channel before public disclosure.
